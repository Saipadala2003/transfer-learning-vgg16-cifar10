# Task 3: Dataset Preparation and Preprocessing for Deep Learning — IMDB Reviews

## Objective
Prepare the IMDB Reviews Dataset for a deep learning application through exploratory data analysis, data-quality checks, text cleaning, feature transformation, and train-validation-test splitting.

## Dataset
The implementation uses `tensorflow.keras.datasets.imdb`. The dataset provides 25,000 training reviews and 25,000 test reviews with binary sentiment labels (negative/positive).

## Preprocessing Pipeline
1. Load the IMDB dataset.
2. Decode integer sequences into readable reviews for EDA.
3. Inspect dataset shape and sentiment distribution.
4. Analyze review-length distribution.
5. Check missing, empty, duplicate, invalid-label, and very short records.
6. Remove invalid/empty records.
7. Normalize text: lowercase, remove HTML tags, URLs, non-alphabetic characters, and repeated whitespace.
8. Split the original training set into 80% training and 20% validation using stratification.
9. Fit TensorFlow `TextVectorization` on training text only.
10. Transform train/validation/test text into fixed-length integer sequences (10,000-token vocabulary, length 250).
11. Save NumPy tensors and cleaned CSV files.

## Data Quality
The notebook explicitly checks for missing values, empty reviews, duplicate reviews, invalid labels, and very short records before feature transformation.

## Important Dataset-Specific Note
The assignment mentions image augmentation as an approach for image datasets. IMDB is a text dataset, so image augmentation is not applicable. Optional text augmentation methods are documented, while the core pipeline uses conservative text cleaning and feature transformation.
